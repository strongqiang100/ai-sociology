## 这是什么

**一个把「判断方法」而不是「结论」交付给你的开源项目。**

市面上的 AI 内容大多在给答案：什么会火、什么会被淘汰、哪个工具必装。这个项目反着来 ——
它不预测结果，它交付**一套能把问题问准的方法**，以及承载这套方法的可安装资产。

具体包含三层东西：

| 层 | 内容 | 形态 |
| :--- | :--- | :--- |
| **方法层** | 16 册推演框架（公理、定理、变量盘查、结构判断） | Markdown 知识模块 |
| **角色层** | 8 个专家 / 专家团，每个只管一个切口 | 可安装的 Agent 包 |
| **工具层** | 6 个技能，能在任意对话里被自动调用 | 可安装的 Skill 包 |

三层的价值不同：**方法层可以被抄，角色层可以被替代，唯独"这套判断方式"本身是别人拿不走的。**
所以本项目把方法层完整开源 —— 抄得走文本，抄不走判断力。

### 一句话定位

> **生成成本趋零之后，稀缺的不是内容，是「值得被复述的那一句」。**
> 以及更根本的：**当答案越来越便宜，问题就越来越贵。**

## 它不是什么

这一节比上一节重要。**划清边界，这套东西才不会变成它反对的样子。**

| 它不是什么 | 原因 |
| :--- | :--- |
| **不是信息核验工具** | 不做"真 / 假"二分。它判断的是**这条说法是事实还是故事、对谁意味着什么** |
| **不是投资建议** | 产业与算力部分只做结构研究框架，**不对任何标的作出判断** |
| **不是心理咨询或诊疗** | 涉持续失眠、功能受损、自伤念头，**明确建议寻求专业帮助** |
| **不是流量技巧** | 内容模块只讲"什么值得被记住"，**不承诺爆款、不教投放** |
| **不是求职简历优化** | 只做职业结构判断，不做简历优化与面试辅导 |
| **不卖安慰，也不卖恐惧** | 两者看起来对立，**实际都让人失去行动能力** |

> 最后一条是本项目最看重的原则。所有输出都执行同一个姿态：
> **承认风险真实存在，同时指出它有边界、有变量、有可操作的部分。**

## 主结论与两条公理

整套推演从两条公理出发，其余全部是推论。

### 两条基础公理

| 公理 | 内容 | 它推出什么 |
| :--- | :--- | :--- |
| **A1 · 注意力有限** | 注意力不可复制、不可并行、不可存储 | 内容供给增长快过筛选效率 → 瓶颈从"能不能生产"移到"能不能挑出来" |
| **A2 · 目标差异** | "它懂我"不等于"它替我办事" | 智能的能力会进步，**但它与你利益是否一致，不会随能力自动进步** |

### 主结论

> **AI 的能力会进步，但它与你的利益是否一致，不会随能力自动进步。**

这条结论推出的三个可直接使用的判断：

| 判断 | 一句话 |
| :--- | :--- |
| **目的质量** | 一个系统可以完全听话、性能极高，但如果被要求执行的目标本身是贫瘠的，**它仍然会把未来推向贫瘠**。这比"AI 会不会造反"重要得多 |
| **两种尊严** | **能力尊严**（我比别人强）被压缩；**位置尊严**（没有我这件办不成）被抬高 —— 方向相反 |
| **责任不可转移** | 你没法开除、判罚或让它赔钱。所以 **AI 写得多好，方案总得有人签名。谁签，谁就值钱** |

另有四条统一口径贯穿全部资产：

```text
现场类工作    晚到不等于不到，只是延时
结构性处境    这是速度问题，不是你的问题
产业结构      慢不等于不到；不得用"物理有上限"去安慰
职业判断      被替代的是"能被完整写下来的工作"，不是"低端工作"
```

## 快速开始

### 方式一：直接安装（推荐）

从 [`dist/`](dist/) 下载对应压缩包，导入你使用的 AI 客户端即可。

```bash
# 例：下载主专家
curl -LO https://github.com/strongqiang100/ai-sociology/releases/latest/download/ai-sociology.zip
```

**专家 / 专家团**：在客户端打开「专家中心 → 我的专家」选择创建（专家团请选「创建专家团」），
或登录开放平台在 `发布管理 → 专家 → 创建` 上传 zip。

**技能**：`发布管理 → 技能 → 创建` 上传 zip；上传后在页面配置头像、类目与展示分类。

> 每个资产在创建时会与包内的 `name` 绑定，**不要把新包传进旧资产**。

### 方式二：克隆源码

```bash
git clone https://github.com/strongqiang100/ai-sociology.git
cd ai-sociology
```

`experts/` 与 `skills/` 下是**完整可用的资产源文件**，可直接拷进客户端的资产目录：

```text
<客户端资产目录>/
├── experts/ai-sociology/
├── experts/ai-sociology-roundtable/
└── skills/ai-sociology-variable-audit/
```

### 方式三：只读知识

不想安装任何东西也可以直接用 —— 16 册框架全部是纯 Markdown：

```bash
open docs/02-framework.md      # 框架总览
ls experts/ai-sociology/skills/ai-sociology-framework/references/
```

### 本地校验

```bash
python3 scripts/validate.py     # 校验全部专家包与技能包是否符合规范
```

校验覆盖：包结构、必填字段、YAML 可解析性、名称规范、目录层级、文件名编码、压缩包完整性。

<details>
<summary><b>圆桌的 7 位 Agent（点击展开）</b></summary>

<br>

**团队分工：一个人不可能同时把六个方向都想到深处。混着谈的结果，是每一样都停在"有道理"。**
圆桌强制分工，每位成员只做一件事，最后交主理人编成一条主线。

| 名字 | 席位 | 只负责 | 绝不越界做 |
| :--- | :--- | :--- | :--- |
| **何执言**（主理人） | 首席议题主编 | 路由、编排、汇编成一条主线 | 不代写任何成员的专业产出 |
| **甄本真** | 哲学与人的根据 | 把问题问准（能力 / 意识 / 目的三分、两种尊严、两种理性） | 不给人生答案，不裁决意识 |
| **关知人** | 人性与欲望结构 | 技术的常量侧（欲望、比较、羞耻、惰性） | 不评价具体的人，不做道德训诫 |
| **任重之** | 职业结构与责任判断 | 三层结构 + 四维打分 | 不做简历优化，不评具体公司 |
| **江观澜** | 社会趋势与结构分层 | 分层、信任、共同体、代际 | 不做政治预判，不做地域比较 |
| **宁怀安** | AI 焦虑的结构降解 | 四种焦虑分离 + 两栏清单 | 不做心理诊断 |
| **秦有疆** | AI 的物理边界与节奏 | 物理上限链 + 事实还是故事 | 不做投资建议 |

**五个预设 Workflow**：`W1 我会不会被替代` · `W2 我很焦虑` · `W3 这到底意味着什么` ·
`W4 我该学什么` · `W5 这条说法可信吗`

</details>

### 技能（6 个）

技能是**教 AI 按步骤做事的方法包**，可在任意对话里被自动调用 —— 与"有身份的角色"（专家）是两种形态。

| 技能 | 标识 | 触发场景 | 对应席位 |
| :--- | :--- | :--- | :--- |
| **AI社会学 · 变量盘查** | `ai-sociology-variable-audit` | 一件事会不会发生、值不值得 | — |
| **AI社会学 · 人的位置** | `ai-sociology-human-position` | 人还有什么价值、我该往哪走 | 甄本真 |
| **AI社会学 · 人性常量** | `ai-sociology-human-nature` | 人为什么会这样（累、比、不动、痛） | 关知人 |
| **AI社会学 · 社会分层** | `ai-sociology-social-strata` | 我们这一代会怎样、谁会被落下 | 江观澜 |
| **AI社会学 · 焦虑分离** | `ai-sociology-anxiety-decomp` | 我心里不舒服、我怕 | 宁怀安 |
| **AI社会学 · 岗位扫描** | `ai-sociology-role-scan` | 我这份工作怎么样 | 任重之 |

<details>
<summary><b>六个技能的触发边界是怎么划开的（点击展开）</b></summary>

<br>

六个技能都跟 AI 有关，**不划开边界就会互相抢触发**。所以每个技能的 `description` 里写了互斥的触发词：

| 用户在问 | 该触发谁 |
| :--- | :--- |
| 一件事**会不会发生** | 变量盘查 |
| 人还有**什么价值** | 人的位置 |
| 人**为什么**会这样 | 人性常量 |
| **我们这一代**会怎样 | 社会分层 |
| **我心里不舒服** | 焦虑分离 |
| **我这份工作**怎么样 | 岗位扫描 |

**一句话里同时出现几种时，顺序是：**

```text
先结构（分层 / 岗位） → 再机制（人性） → 最后感受（焦虑） → 需要时抬到哲学层（人的位置）
```

先处理感受会让人觉得在被敷衍。

</details>

## 使用示例

### 变量盘查：不问"会不会"，问"取决于什么"

```text
用户  所有人都在说这件事会改变一切，帮我把"会改变什么"拆成可追踪的清单。

输出  一、问题归一化
        事实问题 / 条件问题 / 价值问题 —— 三类分开标注

      二、八问
        | # | 问题 | 现状 | 已知/未知 | 它变了会怎样 |
        （不知道就写"未知"，不用推测填空）

      三、这个判断的瓶颈（只说一个）
        八个都重要等于没说

      四、观察信号（3—5 个）
        盯什么 · 多久看一次 · 看到什么说明它在往哪走

      五、判词与证伪条件
        出现 ____ 说明这个判断错了
```

### 焦虑分离：先分开，再处理

四种焦虑被压成一团时，用治 A 的办法去治 B 只会加重：

| 类型 | 解法 | 徒劳的做法 |
| :--- | :--- | :--- |
| **能力焦虑**（我会的不值钱了） | 可拆解、可训练 | 泛泛地"提升自己" |
| **位置焦虑**（我的位置会被占） | **换赛道，不是加速** | 在同一条路上更努力 |
| **意义焦虑**（我做的事没意义了） | **重新选择目标** | 提升效率（会加重） |
| **羞耻焦虑**（别人会认为我不行） | **去羞耻化** | 学更多技能（无效） |

> **四种问题只有第一种能靠"努力"解决。**

### 岗位扫描：识别"伪安全区"

把岗位拆成三层，再用四个维度打分：

| 层 | 被冲击的顺序 | 为什么 |
| :--- | :--- | :--- |
| **任务层** | 最先 | 任务能被完整写下来，就能被接手 |
| **关系层** | 居中 | 关系需要长期积累，依赖"对方认识你" |
| **责任层** | 最后，且最难 | **责任只能停在能被惩罚的主体上** |

**打分维度**：可写性 · 可签字性 · 到场性 · 关系性

```text
四维全低                    → 高危，必须换域
可写性低 + 其余至少一项高   → 安全区，把那项做深
到场性高 + 其余全低         → 伪安全区，最危险
```

> **为什么第三种最危险**：因为"慢"容易被误读成"不会到"。
> 统一口径是 —— **晚到不等于不到，只是延时。**

### 圆桌：六个席位看同一件事

```text
用户  我感觉自己正在被淘汰，但说不清到底怕什么。

圆桌  W2 编排：宁怀安（先分离四种焦虑）→ 关知人（机制）
               → 江观澜（结构归因）→ 任重之（可行动部分）

      汇编纪律（四条，缺一条这份答复就废了）：
        1. 必须有一句能被复述的收口
        2. 既不安慰也不恐吓
        3. 必须同时给"代价"和"可操作的部分"
        4. 必须标出不确定处
```

## 设计原则

这套东西能被复用，靠的是几条硬规则，而不是内容的多少。

### 1. 每册必须挂回主线

任何一册的交付前都要先回答一句：**这件事改变了普通人的什么？**

答不出来，说明它跑偏了 —— 它会退化成一个"什么都能聊"的万金油工具书，
**而这套框架的价值恰恰不在工具。**

### 2. 不给结论，给路径

| 做法 | 结果 |
| :--- | :--- |
| 给结论 | 结论会过期，且用户下次仍然不会判断 |
| **给路径** | 判断力可以迁移，**这才是真正被交付的东西** |

### 3. 必须给证伪条件

任何预测类输出，没有"**错了怎么认**"就不算完成 —— 那只是立场，不是预测。

### 4. 必须同时给代价与可操作的部分

```text
只给代价        → 贩卖焦虑，剥夺希望
只给操作        → 廉价安慰，剥夺警觉
两者都给        → 这才是完整交付
```

### 5. 不把结构性问题缩减为个人不努力

这是本项目最看重的底线。

> 旧岗位消失的速度，**快过**新岗位被社会接受的速度。
> 这是个速度问题，不是你的问题。

### 6. 结构趋势不等于个人命运

说完结构必须补这一句，**否则这套分析就变成了宿命论**。

### 7. 深度来自强制分工

给每个席位划一条"绝不越界做"的线。没有越界清单，成员会互相覆盖，
最后每一样都停在"有道理"的层面。

## 贡献

欢迎贡献。开始之前请先读 [CONTRIBUTING.md](CONTRIBUTING.md)。

```bash
# 1. Fork 并克隆
git clone https://github.com/<your-name>/ai-sociology.git && cd ai-sociology

# 2. 修改后本地校验（必须全绿）
python3 scripts/validate.py

# 3. 提交并开 PR
git checkout -b feat/your-change
```

**提交前自检**：

- [ ] `python3 scripts/validate.py` 全部通过
- [ ] 新增模块已登记进 `docs/02-framework.md` 与对应 `SKILL.md` 的导航表
- [ ] 新模块卷首写了「与主结论的关系」
- [ ] 没有把推测包装成定律，预测类内容附了证伪条件
- [ ] 未引入真实姓名、公司、客户或渠道信息

**最容易被漏的一步**：模块写进 `references/` 但没登记进导航表 ——
那样 AI 在对话里根本不会去读它，**等于白写**。
