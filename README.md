# AI社会学

## 人的有限性、生成的扩张与社会秩序的重组

**AI Sociology · 开放理论体系与研究工具**

[English](README.en.md) · [中文总纲](theory/01-foundations.zh-CN.md) · [五卷目录](theory/README.md) · [参考文献](theory/REFERENCES.md)

当答案、图像和服务变得更容易获得，人的时间、选择、关系和工作会怎样改变？

一份报告写得更快，审阅它是否也更轻松？工作省下了时间，谁能决定这段时间的用途？当制作内容越来越便宜，哪些人的作品仍然能被看见？

这里从这些具体问题出发，讨论时间、注意、情绪、工作、关系与社会分配。每一项判断都保留成立条件，也考察结果可能相反的情形。

**研究版 0.1.0 · 2026-09-22 · 工作论文**

16 项基础原则 · 16 个领域 · 128 个变量 · 64 条条件性推演 · 8 个形式模型 · 中英文对应

这是一套开放的研究框架。推演有明确假设，尚未被验证的路径保留为假说；不以固定结论替代研究。

## 核心问题

**有限性。** 时间、注意与恢复有边界，但具体容量、支持条件和控制权可以改变。

**条件性贬值。** 生成价格、形式稀有性、信号效力和技能回报是不同变量；任务价格变化不等于人的价值变化。

**分叉机制。** 同样的能力进步，在不同需求、所有权、议价与制度条件下，可能产生相反结果。

**开放结论。** 每项重要推演都需要边界、替代解释和能够削弱它的观察。

## 继续研究

在仓库根目录运行，无需额外 Python 依赖：

```bash
python3 scripts/explore_theory.py --stats
python3 scripts/explore_theory.py --variables V009 V057 V098 V097 --order 3 --limit 4
python3 scripts/check_theory.py
```

枚举器覆盖 128 项变量的 **11,017,504** 个二至四元无序候选组合。候选组合不等于已推导或已证明的因果关系。具体机制从 [64 张推演卡](theory/03-derivation-pool.zh-CN.md)和[研究提案模板](theory/templates/research-proposal.md)继续扩展。
