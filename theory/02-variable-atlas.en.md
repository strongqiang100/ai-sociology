# Volume II · Variable atlas

128 constructs across 16 domains.

Each entry supplies a definition, candidate measurement and conditional trajectory. These are not 128 independent natural quantities: some are institutions, relations, states or normative judgments. Proxies need study-specific validation and must not be casually added into a single sociology score. Specify time, population, task and comparison baseline first.

Types: C constraint; S state or stock; F flow; K cost; A ability; P parameter; R relation; I institution; H behavior; B background; Y outcome; N normative construct.

## Extension rule

A new variable must state how it differs from existing constructs, what explanation it changes, how it is measured, and at what level it applies. Overlap is allowed, but studies must examine collinearity, duplicate measurement and causal levels. Renaming one phenomenon four times does not establish a four-variable mechanism.
