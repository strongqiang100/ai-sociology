# 岗位扫描

## 这个技能解决什么

"我这个岗位会不会被替代"——**这个问题问错了层级。**

职业名称消失的速度，远慢于岗位内容的改写速度。正确的层级是：

> **这份工作由三层构成：任务层、关系层、责任层。这三层被冲击的顺序完全不同。**

## 两层判断框架

### 框架 A · 三层切分

| 层 | 内容 | 被冲击的顺序 | 为什么 |
|---|---|---|---|
| **任务层** | 具体做什么：写、算、画、整理、检索、审核 | **最先** | 任务能被完整写下来，就能被接手 |
| **关系层** | 和谁做：客户关系、信任、协调、谈判、带人 | **居中** | 关系靠长期积累，且依赖"对方认识你" |
| **责任层** | 出事谁担：签字、背书、赔付、被追责 | **最后，且最难** | 责任只能停在能被惩罚的主体上 |

**关键推论**：任务层被拿走后，**关系层与责任层的价值会相对上升**——
不是它们变强了，是**剩下的人变少了**。

> 所以"我该往哪走"的答案，通常不是"学更多技能"（那是加深任务层），
> 而是**往关系层和责任层移动**。

### 框架 B · 四维打分（各 0—5 分）

| 维度 | 问什么 | 低分意味着 |
|---|---|---|
| **可写性** | 能不能被完整文字化、步骤固定 | 低分 = 危险（优先被接手） |
| **可签字性** | 需不需要人承担后果 | 高分 = 安全（责任壁垒） |
| **到场性** | 需不需要身体到场、手眼协同、非标环境 | 高分 = 安全但**只是延时** |
| **关系性** | 需不需要长期建立的信任与理解 | 高分 = 迁移慢 |

**解读规则（这一步最重要）**：

| 组合 | 判定 |
|---|---|
| 四维**全低** | **高危**——且没有可迁移的部分，必须换域 |
| 可写性低 + 其余至少一项高 | **安全区**——重点是把那一项做深 |
| **到场性高 + 其余全低** | ⚠️ **伪安全区**——最危险，因为"慢"容易被误读成"不会到" |

## 执行步骤

1. **先问清现状**：具体岗位、日常真正在做的任务（不要笼统的职责名）、行业、主要市场。
   **信息不够就先问，不要凭空扫描。**
2. **拆到任务级**：列成编号表。写"整理客户回访记录"，不写"客户维护"。
3. **三层归一**：把每项任务归入任务层／关系层／责任层，算出各层占比。
4. **四维打分**：逐维度给分并写依据。
5. **判定安全区性质**：安全区 / 伪安全区 / 高危区。
6. **列五样提供物**：这份工作失去时，会同时失去什么？（见下）
7. **给"反而会涨价的部分"** —— **这一步不可省**。
8. **给一条主路径 + 一句证伪条件**。

## 职业不只是收入

判断职业风险时必须同时看五样，**只看收入的判断，会在最不该乐观的地方乐观**：

| 提供物 | 失去时会怎样 |
|---|---|
| 收入 | 直接可见的生活压力 |
| **身份** | "我是做什么的"答不上来 |
| **尊严** | 被人问起时想转移话题 |
| 社会关系 | 失去"同类"的感觉 |
| **长期规划** | 不知道三年后该往哪走 |
| **"努力有回报"的预期** | 最致命——动力系统失效 |

## 输出规范

- **一律上表格**：三层切分表 + 四维打分表 + 五样提供物清单。
- **拆到任务，不拆到岗位**。
- **必须给"反而会涨价的部分"**。只说危险是贩卖焦虑。
- **必须给一条主路径和一句证伪条件**（出现什么说明这个判断要改）。
- **涉及招聘数据必须带来源与年份**；查不到就写"待核实"，**不许估计**。
- **区分"没接入"和"接入了但没用上"**——后一种是更普遍、也更难解决的落后。

## 红线

- **不给职业安全感承诺。** 可以讲机制，不能保证结果。
- **不把结构性阵痛说成个人不努力。** 旧岗位消失的速度快过新岗位被社会接受的速度——这是速度问题。
- **"晚到"不等于"不到"，只是延时。** 这是必须带出的口径，用来对冲最常见的虚假安慰。
- **不贬低任何职业。** 被替代的不是"低端工作"，是"能被完整写下来的工作"。
- **不评价具体公司是否裁员**，不预测任何组织的用人计划。
- **不做简历优化、不做面试辅导**——那是另一个工种，本技能只做结构判断。
