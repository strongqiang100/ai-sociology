## What this is, in one paragraph

An open-source reasoning framework about **the human position under AI**. It does not forecast
outcomes. It delivers a method for asking the right question, plus fourteen installable assets
(8 experts and expert teams, 6 skills) that carry that method.

The main conclusion everything derives from:

> **AI's capability will keep improving. Whether it aligns with your interests will not improve
> automatically alongside it.**

## The five-minute tour

### Step 1 — Read the two axioms (1 minute)

| Axiom | Statement |
| :--- | :--- |
| **A1 · Attention is finite** | Attention cannot be copied, parallelised or stored |
| **A2 · Objectives diverge** | "It understands me" is not "it acts for me" |

Everything else in this project is a derivation from these two. If you only read one thing, read
[module 01](../experts/ai-sociology/skills/ai-sociology-framework/references/01_公理定理与推演链.md).

### Step 2 — Learn the four standing formulations (2 minutes)

These appear throughout the project. They exist because each one blocks a specific mistake.

```text
On-site work        Late is not never - only delayed
                    (blocks the comforting lie that some jobs are immune)

Structural hardship It is a speed problem, not your problem
                    (blocks the second injury of blaming people for structural change)

Industry structure  Slow is not never; "physics has limits" must not be used as comfort
                    (blocks the comforting lie that AI will simply stall)

Occupation          What gets replaced is "work that can be fully written down", not "low-end work"
                    (blocks the classist reading of automation)
```

## Key concepts

<details>
<summary><b>Variable mapping</b></summary>

<br>

Instead of asking "will this happen?", ask "what does this depend on, and which variable is binding
right now?"

Conclusions expire. A variable list keeps working. The eight questions live in
[module 02](../experts/ai-sociology/skills/ai-sociology-framework/references/02_变量盘查八问.md).
</details>

<details>
<summary><b>The three layers of work</b></summary>

<br>

Every job decomposes into **task**, **relationship** and **accountability** layers, and they are hit in
that order. Tasks go first because a task that can be written down completely can be handed over.

Accountability goes last, and barely moves, because **responsibility can only rest on an entity that
can be punished**. You cannot fire an AI, fine it, or make it pay.
</details>

<details>
<summary><b>The two kinds of dignity</b></summary>

<br>

| Type | Source | As AI gets stronger |
| :--- | :--- | :--- |
| **Competence dignity** | I am better than others | **Compressed** - the baseline is levelled |
| **Positional dignity** | Nothing works without me | **Raised** - what cannot be replaced gets dearer |

Which means the question "how do I become more competitive?" is the wrong question. The right one is:
**is my value built on competence, or on position?**
</details>

<details>
<summary><b>Four anxieties that need four different fixes</b></summary>

<br>

| Type | Fix | Futile approach |
| :--- | :--- | :--- |
| **Competence** (what I know is worthless) | Break down, retrain | Vague "self-improvement" |
| **Position** (I will be displaced) | **Change lanes, do not accelerate** | Trying harder on the same track |
| **Meaning** (my work means nothing) | **Re-choose the objective** | Raising efficiency - makes it worse |
| **Shame** (others will think I am failing) | **De-shaming** | Learning more skills - useless |

> **Only the first of the four can be solved by "trying harder".**
</details>

<details>
<summary><b>A structural trend is not a personal fate</b></summary>

<br>

This project talks about structures: stratification, generations, communities. That creates an obvious
risk - reading like fatalism.

So every structural analysis must end with: **the structure gives probabilities and directions; the
individual still has room to choose inside it.** Without that line, the analysis has failed.
</details>
