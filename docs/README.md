## Three ways to read this project

**If you are here to use it** — read
[01 · Getting started](01-getting-started.md), then install whatever you need from [`../dist/`](../dist/).

**If you are here to understand it** — read
[02 · The framework](02-framework.md) in order. The modules are designed to be read sequentially, but
each one stands alone.

**If you are here to contribute** — read
[CONTRIBUTING.md](../CONTRIBUTING.md) first. It takes ten minutes and will save you a rewrite.

---

## The one thing to remember

> **This project delivers a method of judgement, not a set of conclusions.**

Everything else follows from that. If a document here ever reads like a confident answer to an
unanswerable question, that is a bug — please [report it](https://github.com/strongqiang100/ai-sociology/issues/new/choose).
