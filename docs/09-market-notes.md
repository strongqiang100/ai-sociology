## The two conclusions

### 1 · The skill market is saturated — but not in this category

Which means the question has to be split:

| Question | Answer |
| :--- | :--- |
| Can a judgement-type asset break into the utility top 100? | **No. Do not try.** |
| Is anyone occupying the judgement category? | **Almost nobody. It is empty.** |

Being empty is not the same as being lucrative. It is, however, a real position.

### 2 · The real risk is not competition — it is that nobody searches

This is the important one.

> **Nobody wakes up wanting to install a skill about where humans stand.**

They install a PDF skill because they have a PDF today. They install a social-media skill because they
have a post to publish. **A judgement need has no "needed today" trigger** — it lives inside a state of
confusion, not on a to-do list.

So the honest conclusion: **do not expect marketplace search to generate installs for this project.**
That is not pessimism; it is arithmetic.

## What that means for this project

### The value is in three places, none of which is traffic

| Value | Explanation |
| :--- | :--- |
| **Trust placed ahead of the sale** | When someone searches for this topic and finds a published asset, that is worth more than a business card |
| **An attributable asset** | Curated lists and community write-ups accumulate attribution. An asset's install count survives updates |
| **A companion to content** | The reasoning published as video or text becomes something a reader can install and use. **This is the real distribution channel** |

**One line**: these assets are an **extension of content**, not a customer-acquisition channel.

### Which changes the priority order

1. **Ship the skills as companions to content.** A closing line in a video: "this is a skill now, install
   it and you can ask it any time." **Installs come from content, not from search.**
2. **Aim for official curation.** Community marketplaces are curated — being selected matters more than
   natural ranking. Getting into a developer programme or a community showcase is worth more than
   shipping three more assets.
3. **Lead with the most immediately useful asset.** Of the six skills, **Variable Audit** is closest to a
   daily-use action. It is the only one with any realistic chance of organic discovery.
4. **Start free, decide later.** Opening a payout account requires at least one reviewed asset, and
   **the payment model is locked at release**. Get through review first.

## A correction this project owes

An earlier internal note concluded that **the platform offered no revenue mechanism** — that skills
list free and there is no way for a creator to earn.

**That was wrong.** The conclusion came from reading only the public documentation, which indeed
contains no revenue provisions. But the platform's own interface has a **revenue section** supporting
one-off and monthly pricing.

**The lesson generalises**: to establish what a platform can do, read its interface, not only its
documentation. Documentation lags the product.

The second, larger lesson is the one this whole framework is built on: **"the documentation does not
say so" is not the same as "it is not so."** One is an absence of evidence; the other is evidence of
absence. Conflating them is the single most common error in exactly the kind of trend analysis this
project exists to improve.
