# 08 · 视频生产分册

> **与主结论的关系**：生成工具让更多人有机会把画面做出来，**但被看见、被记住的机会，不会自动随之平均分配**。
> 这一册处理的是：当"做出来"不再稀缺，**什么变成了新的瓶颈**。

---

## 一、把生产拆成流水线

| 环节 | 输入 | 输出 | 可复用点 |
|---|---|---|---|
| 选题 | 主结论 | 一句话收口 | 题材库 |
| 脚本 | 收口句 | 逐秒结构 | 结构模板 |
| 分镜 | 脚本 | 镜头清单 | 分镜模板 |
| 素材生成 | 分镜 | 画面片段 | 提示词积木 |
| 配音 | 脚本 | 音轨 | 音色 / 语速规则 |
| 剪辑 | 素材 + 音轨 | 成片 | 剪辑模板 |
| 品质门禁 | 成片 | 通过 / 打回 | 检查清单 |

**关键**：每一步都要"可单独替换"。某个环节的工具换了，整条线不能塌。

## 二、品质门禁（成片前必查）

- [ ] 首帧大字钩子 ≤8 字，且是断言不是问句
- [ ] 前 3 秒内有反常识陈述
- [ ] 数据带来源（或明确标了"示例，非实测"）
- [ ] 收口句只出现一次，且能独立听懂
- [ ] 全片只有一个主结论
- [ ] 音画同步、无跳帧、无字幕错位
- [ ] 去掉产品名和日期后，内容仍成立

## 三、画面提示词控制不住的治法

这是本地生成最普遍的痛点。三个动作按顺序做：

1. **把提示词拆成积木**：主体 / 动作 / 镜头 / 光线 / 风格 / 负面，各一格，**不要写成一长句**。
2. **固定变量，只动一个**：一次只改一格，才知道是哪一格导致了变化。同时改三格，等于抽卡。
3. **建"可用片段"库**：跑出来的好片段立刻归档，标清用了哪组积木。下次从库里拼，不从零开始。

> **抽卡多的根因几乎总是：提示词没有结构化，导致结果不可复现。**

## 四、降级路径（画面做不出来时）

先降画质，再降时长，最后降复杂度。**不要为了一个镜头卡住整条片子。**
成片的价值主要在结构与收口句，不在单个镜头的精度。

## 五、慢≠安全

atoms 世界（现场、制造、照护）的替代速度确实慢，但那只是**延时，不是豁免**。
同理：视频生产自动化得再快，如果没有结构和判断，也只是更快地产出同质内容。

## 六、挂回主线的一句话

**工具把"做出来"变便宜了，于是"为什么值得看"变贵了。**
