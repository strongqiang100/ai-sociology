# 03 · 表达与选题规范

---

## 一、一句话定位

> **一个 AI 从业者的时代观察：不教你追热点，研究 AI 如何改变欲望、影像、关系与真实。**

- **核心钩子**：这里的内容，是做给两年后的你看的。（"两年后"是内容耐久性的表达，不是宣称能准确预知未来）
- **收束句**：看 AI 的变化，找人的位置。
- **一句话简介**：写给两年后的你。透过 AI，讨论人的工作、关系与选择。
- **内部定位**：以 AI 为入口，研究持续影响人的社会机制，寻找普通人在技术变迁中的生存、发展与自主空间。

**受众画像**：对 AI、科技、短视频、影像生产有明显兴趣；能听懂 Sora、Veo、本地部署、显卡、模型、工作流这些词，但不一定是技术开发者；有一点文学和社会议题兴趣（听到川端康成、刘慈欣、卡夫卡、博尔赫斯、奥威尔、赫胥黎不觉得陌生）；不喜欢油腻的成功学，也不喜欢纯学院腔。

**核心判断**：不是给观众上课，而是**替观众把一种"我好像也感觉到了，但说不清"的东西说出来**。

---

## 二、四个隐含站位（每篇都在，但不必说出口）

| 站位 | 具体要求 |
|---|---|
| **时间尺度**：讲今天，但不止于今天 | 可以跟进新模型、新产品和新闻，但它们是观察社会变化的入口，不是内容的全部价值。**删除版本号和发布日期后，文章仍应保留值得讨论的问题。** |
| **解释深度**：追到机制，不停在功能 | 从"AI 能做什么"追到"什么不再稀缺、谁的目标不同、谁在决定规则、谁承担代价"。思想与哲学通过问题和推理体现，不靠反复宣布自己有深度。 |
| **观察位置**：回到普通人的生活 | 讨论生产力，最终落到普通人的生存与发展空间：靠什么谋生、怎样参与创造、如何获得机会、保留哪些判断和选择。**人的价值也不只等于劳动市场价格，要保留关系、尊严和生活本身的尺度。** |
| **创作方式**：通过深度对话形成判断 | 来自与 AI 深入聊天、反复追问、核验和整理思路。不能描写成"随手让 AI 批量吐出文案再挑一篇"，也不能为了增强真实感虚构个人经历。 |

## 三、文案结构

### 推荐路径（素材清单，不是必装模板）

```
生活入口 → 承认体验 → 追机制 → 文学参照 → 回到处境
```

要点：
- **不要一开头就讲概念。**
  - ❌ 今天我们来聊审美通胀。
  - ✅ 你有没有发现，现在刷到 AI 视频，第一秒确实挺震撼，但划过去以后，几乎什么都没留下。
- **承认体验**：先说清"这是真实的进步"。把便利写成愚蠢，是这一类内容最容易犯的错。
- **追机制**：篇幅留在这里。
- **文学参照**：点到即止。
- **回到处境**：一句能自检的话，不是一份行动清单。

### 硬要求：三个必答问题（替代固定八段式）

1. **发生了什么？**
2. **为什么值得重新理解？**
3. **它改变了谁的什么？**

文学引用、从业者经历和概念命名按论证需要加入，**不要求每篇齐全**。框架过于整齐会让不同主题听起来像同一个模板。

### 一篇文章只设一个主结论

其他好问题进选题储备，不强行在同一篇里同时讨论就业、教育、婚姻和整个文明。

## 四、语言标准

### 1. 少用大词，先说体感

| 不要直接说 | 改成 |
|---|---|
| 空虚 / 虚无 / 异化 / 后真实 / 视觉通胀 | 爽是爽，但留不住。 |
| — | 看完了，但不想追下一集。 |
| — | 明明很炸，却记不住一个镜头。 |
| — | 刷的时候挺上头，放下手机以后又觉得没什么。 |

概念放在中后段，再轻轻命名。

### 2. 不要替普通人下判断

- ❌ 这些内容没有意义。
- ✅ 它们不是传统意义上的剧情，也不是知识内容，但它们确实提供了一种更轻、更快、更不用理解的刺激。

普通人觉得小猫跳舞、怪兽打架、梗图翻炒有意思，那它就有它的意义。任务是解释它为什么会成为一种新的内容形态，**不是否定它**。

### 3. 要像聊天，不像汇报

✅ 可以说：说实话，我一开始也没太当回事。/ 但后来我发现不对。/ 这事不能只从技术看。/ 如果你在 AI 行业里待一段时间，就会发现这里面有点微妙。/ 这个点不好讲，因为它不是简单的对错。

❌ 少说：本质上 / 从某种意义上 / 因此可以得出 / 综上所述 / 这反映了。

### 4. 文学引用要轻，不要炫

每期最多一到两个参照，点到即可，**不写作者介绍**。

| 作品 | 用来讲什么 |
|---|---|
| 川端康成《睡美人》 | "没有回应的对象"与欲望里的他者消失 |
| 刘慈欣《时间移民》 | 未来文明、身体边界与人类存在形式被技术推远 |
| 卡夫卡《变形记》 | 一个人突然变成"不可理解的对象"以后，社会关系如何改变 |
| 赫胥黎《美丽新世界》 | 快乐、消费和稳定如何变成控制人的方式 |
| 奥威尔《1984》 | 真实被权力和媒介改写 |
| 博尔赫斯《小径分岔的花园》/《巴别图书馆》 | 无限选择、无限文本和意义迷宫 |
| 《论语·述而》"不愤不启，不悱不发" | 动力不能外包；困惑需要一个不被解答的窗口期 |
| 《三体》 | 只看逻辑结构与推理方式，不搬人物和结论 |

### 5. 从业者经历要像顺手说出来

每期可以穿插 1—2 个实践细节，但不要写成简历，也不要炫耀工具。

✅ 可用表达：前几天有个老板问我，本地部署是不是一定要上更好的显卡。/ 有时候一个话题，我会跟 AI 聊到半夜，开最高推理，一层一层往下追问。/ 我试过把同一个素材反复生成几十版，第一版觉得惊艳，第十版开始麻木，第三十版就只剩下判断。

**尺度**：可以说"跟 AI 聊到半夜"，不要频繁说得过于戏剧化；不要说成卖惨或装深沉，语气要像顺口讲一个工作习惯。

## 五、短视频内容单元标准结构

| 环节 | 时长 | 要求 |
|---|---|---|
| **首帧大字钩子** | 0—1 秒 | 不超过 8 个字，必须是**反直觉断言**，不能是问句。大字居中，占画面高度 1/3 以上。 |
| **反常识陈述** | 1—4 秒 | 一句话把观众的默认认知打碎。口语化，不许用书面语。 |
| **数据锚点** | 4—12 秒 | 一个具体数字，**带来源**。"7.43 亿条招聘数据"比"大量数据"有力 10 倍。 |
| **定理收口** | 12—18 秒 | 一句可以被人复述给别人听的话。**这是唯一会被传播的部分。** |
| **行动指令** | 18—22 秒 | 一个具体的、今天能做的动作（按内容类型选配，不强制每篇都有）。 |

### 首帧钩子库（按强度排序）

| 钩子 | 对应内容 |
|---|---|
| 丰裕不等于稳定 | 定理四 · 最反直觉、最有高度的一条 |
| AI 拼的是电，不是聪明 | 约束链 · 电力与算力 |
| GPU 到货 ≠ 算力到货 | 三重墙 · 芯片能不能点亮 |
| AI 进得来屏幕，进不来现场 | 概念一 · bits 与 atoms |
| AI 不裁岗，它拆岗 | 定理一 · 任务重组 + 人工格比喻 |
| 未来最贵的不是钱 | 定理五 · 智能入口成为新分层 |
| AI 不背锅 | 定理三 · 责任壁垒 |
| 答案越来越便宜，问题越来越贵 | AI 时代学习 · 提问能力 |
| 未来不是观点，是变量 | 元原则 · 世界观宣言 |
| 省下来的时间，不会自动变成你的 | 公理 A1 · 注意力的生活形态 |

## 六、标题规则

不要太学术，也不要太低俗。优先使用这类表达：

- 为什么 AI 视频越像大片，越让人追不动？
- 一个梗被 AI 炒一百遍，为什么你还是会停下来？
- 为什么不存在的怪兽，会让人忍不住多看三秒？
- 最可怕的不是假视频，而是我们懒得问真假了
- 为什么 AI 越懂你，真人越显得麻烦？

**少用**：审美通胀的社会学解释 / AI 时代的后真实危机 / 无意义内容的价值化 / 欲望对象化与技术伦理。这些概念可以在正文里出现，但不要直接做封面标题。

## 七、成稿检查（六问）

1. **去掉产品名和版本号，这篇是否还有值得讨论的问题？**
2. 是否从技术变化追到了人的机会、关系、价值或选择，而不是只罗列功能？
3. 两年后的观众能否从中获得一种**判断方法**，而不只是看到一条旧新闻？
4. 是否清楚区分**已发生的事实、成立所需的条件、我们自己的价值判断**？
5. 是否**通过内容本身体现定位**，而不是反复自称深刻、领先或永恒？
6. 结尾是否回答了：**这件事改变了普通人的什么？观众因此多了哪一种判断处境的能力？**

### 六条边界

1. 栏目介绍、置顶内容可以完整表达"两年后的你"；普通作品**优先从具体生活切入**，不统一加宣言式片头。
2. 不要求每篇都给行动清单，**不把结构性问题缩减为个人不够努力**。
3. 不贬低工具教程和资讯内容——差异在观察尺度和问题选择，不是宣称别人没有价值。
4. **不承诺内容永不过时，不把推测包装成永恒定律。**
5. 保留生活入口、紧凑推导、少量文学或哲学参照、有分量的短句，以及回到个人处境的原有风格。
6. **不要用漂亮的总结替代进一步解释**——那是"观点很顺，但听完没有多想明白多少"的根源。

## 八、对话感：用反问建立，不用语气词堆

把观众可能提出的异议纳入推理：

> 你可能会说，我刷个怪兽视频，就是图个新鲜，为什么非得追下一集？
> 　对，这类视频已经满足了你的需要。值得往下问的是：当越来越多人都能提供这种新鲜，创作者靠什么让你下次还认得他？

这是对话式的论证，**不要求两个角色出镜**。它比增加"说实话""这个事情很微妙"等过渡语更能推动理解。

### 承认一个现象的吸引力，再追问

可复用的三段式：**承认它成立 → 指出它成立的条件 → 追问人的处境发生了什么。**

示例（也是"活人感"的正确来源——具体判断、犹豫和对例外的承认，而不是口头禅或表演）：

> 如果这个镜头只是为了展示模型能做到什么，那它已经完成任务了。可如果我想让人接着看故事，光是漂亮还不够。

## 九、表达状态建议

**讲述者气质**：不是传统意义上的"老师"，也不是高高在上的专家，而是一个长期接触 AI 工具、客户、模型和内容生产的人，坐下来把行业里看到的东西讲清楚。三种气质同时存在：**逻辑感 / 生活感 / 有智慧但不高高在上。**

- **要有的**：面对受众但不太"摆拍"；有一点思考感，但不阴沉；像跟一个熟人聊一个严肃但有趣的问题。
- **要避免的**：过商业、过精致；"导师""大师""成功人士"气质；过度表演。
- **表达状态**：开头从生活细节切入；语速中等偏慢；句子不宜太长，要有停顿；允许出现"说实话""这个点挺微妙""我一开始也没太当回事"这类生活化表达。
- **不要连续使用**："本质上、因此、综上、从某种意义上"这种汇报词。
