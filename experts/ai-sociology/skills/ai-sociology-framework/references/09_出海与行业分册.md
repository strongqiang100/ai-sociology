# 09 · 出海与行业分册

> **与主结论的关系**：责任不可转移（公理三）。**凡是需要"有人签字、有人兜底"的环节，AI 越强，人越贵。**
> 出海业务的护城河，恰恰在于它是 atoms 世界的（要样品、要交付、要上门）+ 责任闭环的（要签合同、要担责）。

---

## 一、进入一个陌生行业：四段认知

1. **老板真正关心什么**（不是他嘴上说的）
2. **海外采购商第一眼看什么**（决定他要什么证据）
3. **常见业务场景与客户痛点**
4. **拜访要问什么**

**行话的作用不是显得专业，是让对方觉得"你懂我在担心什么"。**

## 二、行业通用规律（跨行业复用）

| 维度 | 规律 |
|---|---|
| 老板第一痛 | 老客户返单变少，新客户开发慢，渠道不稳定 |
| 第二痛 | 报价被比价压价，低价竞争难脱身 |
| 第三痛 | 小单多、急单多，排期与辅料到位速度决定履约 |
| 采购商第一问 | 你能不能稳定做出来（**交付能力 > 产品本身**） |
| 采购商第二问 | 你能不能按我的标准做（合规与一致性） |

## 三、证据链设计（采购商看证据，不看承诺）

| 行业类型 | 必答证据 |
|---|---|
| 服装 / 家纺 / 箱包 | 面料（成分/克重/手感/洗后变化）、版型尺码、工艺细节、打版与量产周期、MOQ |
| 五金 / 机械 | 精度检测报告、材质证明、模具能力、批次一致性、售后件供应 |
| 3C / 电子 | 认证清单、电池运输合规、固件与 App 配套、一致性记录 |
| 包装 / 印刷 | 材质合规（含食品级）、打样速度、小批量起订、色彩管理 |
| 美妆 / 日化 | 配方与功效宣称合规、包材灌装、MOQ、区域法规差异 |
| 玩具 / 饰品 | 安全标准、年龄标识、小件与锐边、IP 授权风险 |

## 四、竞品对标：五段卡 + 三类差距

**五段卡**：为什么值得看 → 它解决什么问题（**按客户流程拆，不按功能页拆**）→ 该学什么 → **不要硬拼什么** → 客户拿它来比时怎么应答。

**差距归因（处理方式完全不同）**：

| 类型 | 表现 | 处理 | 成本 |
|---|---|---|---|
| **能力差距** | 它真有我们没有 | 补或绕开 | 高 |
| **表达差距** | 能力相当，它说得更清楚 | **改对外表达** | 低、见效最快 |
| **心智差距** | 它先到、有积累 | **不硬拼，换战场** | 极高 |

> **多数"我们不如它"其实是第二类。** 先检查表达，再决定要不要补能力。

**分工话术**：承认对手在什么场景更合适，再给客户一个判断标准。全盘否定对手，客户的第一反应是防御。

## 五、合规：三件事 + 一条边界

卖家的合规主要落在**主体、税务、平台规则**三件事上。
常见坑按严重程度排：目标市场准入资质缺失 > 税务与资金回流结构 > 平台规则与知识产权 > 产品标签与宣称。

**边界**：本分册只做"哪些情况要警惕、什么时候该找持牌机构"的判断，**不替代专业合规意见**。

## 六、拜访问题库（第一次不超过 8 题）

每题的真正价值在**"听到什么答案说明什么"**：

| 维度 | 问法 | 听到什么说明什么 |
|---|---|---|
| 订单结构 | 老客户返单占比多少？ | 返单低 = 开发压力大 |
| 获客现状 | 新客户从哪来？ | 只靠展会/老带新 = 数字渠道空白 |
| 线上资产 | 有没有独立站？谁在管？ | 没站或没人管 = 承接缺口 |
| 内容能力 | 拍过产品视频吗？谁拍的？ | 只有产品图 = 内容表达是短板 |
| 交付能力 | 打版/打样周期多久？ | 周期长 = 快反订单会流失 |
| 合规能力 | 目标市场认证齐了吗？ | 缺认证 = 卡在准入而非获客 |
| 决策方式 | 这类投入谁拍板？ | 老板不拍板 = 决策链更长 |

## 七、挂回主线的一句话

**AI 进得来屏幕，进不来现场。但慢不等于安全，只是延时。**
出海业务现在最大的机会，正是在"只能慢"的那一段里把责任闭环做完整。
