# 07 · 内容与文案分册

> **与主结论的关系**：内容变多不等于选择变好。**供给增长快于筛选效率，注意力就成了更紧的瓶颈**（公理 A1）。
> 这一册处理的是：当生成成本趋零、内容无限供给时，**什么东西还值钱**。

---

## 一、先定那一句话（收口句）

一段内容里，观众只会带走一句话。你真正要设计的不是"整篇文案"，而是**那一句**。

**收口句的三条验收**：
1. **能被复述**：不看画面，听一遍就能说给别人听
2. **有画面或对比**：抽象名词单独出现不算收口
3. **扛得住两年**：把产品名和日期删掉，这句话依然成立

## 二、逐秒结构（短视频）

| 环节 | 时长 | 要求 |
|---|---|---|
| 首帧大字钩子 | 0—1 秒 | ≤8 字，**反直觉断言**，不能用问句。大字居中，占画面高度 1/3 以上 |
| 反常识陈述 | 1—4 秒 | 一句话打碎默认认知。口语化，不许书面语 |
| 数据锚点 | 4—12 秒 | 一个具体数字，**带来源** |
| 定理收口 | 12—18 秒 | 一句能被复述的话——**这是唯一会被传播的部分** |
| 行动指令 | 18—22 秒 | 一个今天能做的动作（选配） |

## 三、钩子的四种有效类型

| 类型 | 句式 | 例子 |
|---|---|---|
| 反直觉断言 | 把默认认知反过来 | 越省力的工具，越练不出能力 |
| 反差数字 | 两个不该并列的数字并列 | 电工涨 56%，AI 工程师涨 15.8% |
| 因果错位 | 结果说对了，原因说反了 | 不是内容变差了，是你变快了 |
| 概念降维 | 把抽象词换成看得见的画面 | 你的活儿在屏幕里，还是屏幕外 |

**无效钩子**：问句、自我介绍、"今天聊聊…"、形容词堆叠、需要上下文的梗。

## 四、爆款拆解表（逐秒）

| 秒数 | 原片内容 | 结构作用 | 判断 |
|---|---|---|---|
| 0—1 | | 钩子 | |
| 1—4 | | 反常识陈述 | |
| 4—12 | | 数据锚点（来源：） | |
| 12—18 | | 收口句 | |
| 18—22 | | 行动指令 | |

拆完必须回答：**它的收口句是哪一句？哪一秒最可能掉人？哪些结构可复用、哪些只是这条内容的运气？**

## 五、选题评分卡（每项 0—5 分）

反直觉强度 ｜ 数据可得性 ｜ 可复述性 ｜ 落点具体度 ｜ 两年后是否成立 ｜ 与已发内容的重复度

**总分 ≥ 22 分才做。** 反直觉强度或可复述性低于 3 分，直接放弃。

## 六、栏目系统（一个选题喂给所有平台）

- **栏目档案**：受众、选题边界、话语风格、不做什么
- **一题多版**：同一主结论，按平台改写钩子与节奏，**不重写结论**
- **复盘表**：哪条该加强、哪条该停、哪条的收口句被复述了

## 七、常见失败诊断

| 症状 | 真实原因 | 处方 |
|---|---|---|
| 完播率低 | 钩子不是断言 | 换钩子，不动正文 |
| 听完没印象 | 收口句太抽象或太长 | 重写收口，压到一句 |
| 点赞高不涨粉 | 只有共鸣没有立场 | 补一个明确的判断句 |
| 评论说"说了等于没说" | 只有观点没有机制 | 补"为什么会这样"的一层 |
| 转发少 | 观众不知道该转给谁 | 补一个具体的使用场景 |

## 八、挂回主线的一句话

**生成成本趋零之后，稀缺的不是内容，是"值得被复述的那一句"。**
