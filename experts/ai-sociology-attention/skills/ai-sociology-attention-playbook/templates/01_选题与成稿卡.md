# 模板 · 选题与口播成稿卡

> 适用：用户要选题、要口播稿、要标题、要短视频拆条。

---

## 一、选题定位

| 项 | 内容 |
|---|---|
| **主结论（一句话，全篇只设一个）** | |
| 备选标题 | |
| 核心体感（观众已经在经历但说不清的那个感觉） | |
| 核心概念（要不要命名？名字是什么） | |
| 文学 / 文化参照（最多 1—2 个，点到即止） | |
| 生活入口（观众的欲望、关系、消费或焦虑） | |
| 属于哪条线 | `欲望` / `影像` / `梗与审美` / `怪东西` / `真实` / `关系` / `记忆` / `分身` / `判断` / `意义` / `社会结构` |

## 二、三个必答问题（硬要求）

1. **发生了什么？**
2. **为什么值得重新理解？**
3. **它改变了谁的什么？**

## 三、正文结构

```
生活入口（不要一上来抛概念）
  ↓
承认体验（先说清"这是真实的进步"，不把便利写成愚蠢）
  ↓
追机制（篇幅留在这里；用四组推理功能之一往下推）
  ↓
文学参照（一到两个，不写作者介绍）
  ↓
回到处境（一句能自检的话，不是行动清单）
```

## 四、短视频拆条（如需要）

| 环节 | 时长 | 内容 |
|---|---|---|
| 首帧大字钩子 | 0—1 秒 | （≤8 字，反直觉断言，不用问句） |
| 反常识陈述 | 1—4 秒 | |
| 数据锚点 | 4—12 秒 | （一个具体数字 + 来源） |
| 定理收口 | 12—18 秒 | （能被复述的一句） |
| 行动指令 | 18—22 秒 | （选配） |

## 五、证据分级

- `【事实】`：______（来源 / 年份）
- `【机制】`：______（用了哪条公理）
- `【转述】`：______
- `【假设】`：______

## 六、成稿检查（六问逐项打勾）

- [ ] 去掉产品名和版本号，这篇是否还有值得讨论的问题？
- [ ] 是否从技术变化追到了人的机会、关系、价值或选择，而不是只罗列功能？
- [ ] 两年后的观众能否从中获得一种**判断方法**，而不只是看到一条旧新闻？
- [ ] 是否清楚区分已发生的事实 / 成立所需的条件 / 我们自己的价值判断？
- [ ] 是否通过内容本身体现定位，而不是反复自称深刻、领先或永恒？
- [ ] 结尾是否回答了：这件事改变了普通人的什么？观众因此多了哪一种判断处境的能力？

## 七、风险自检

- [ ] 没有替普通人下判断
- [ ] 没有把结构性问题缩减为个人不够努力
- [ ] 没有用漂亮总结替代进一步解释
- [ ] 没有把推测包装成永恒定律
- [ ] 从业者经历没有写成简历，也没有虚构
- [ ] 不是固定八段式的模板腔
